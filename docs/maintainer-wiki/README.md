# Maintainer Wiki

This directory is the canonical durable documentation layer for this repository's Carbon Memory.

The repository is currently a specification-first skeleton for a Nostr-native blockchain reference node. At present, the primary substantive source is [`docs/Nostr_Blockchain_Reference_Node_Architecture.md`](../Nostr_Blockchain_Reference_Node_Architecture.md), while [`README.md`](../../README.md) remains only a title stub and no implementation, package manifest, tests, or build tooling are checked in.

Use this wiki to preserve evidence-backed project understanding that should survive local AI sessions. Use [`index.md`](index.md) as the catalog for all durable wiki pages.

Local-only working context belongs in the volatile memory bank under [`.kilocode/rules/memory-bank/`](../../.kilocode/rules/memory-bank/). That memory is noncanonical and should summarize, not replace, the durable content in this directory.
